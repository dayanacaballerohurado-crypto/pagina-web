ESTRUCTURA DEL PROYECTO

Santa_Cruz_Web/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js

index.html:
- Contiene la estructura y el contenido de la página.
- Carga Tailwind CSS y la hoja de estilos propia.

css/style.css:
- Contiene los estilos CSS propios separados del HTML.

js/script.js:
- Contiene la interacción del botón "Ver Comidas Típicas".
- Se conecta con index.html mediante <script src="js/script.js"></script>.

Para abrir la página:
1. Abre index.html en un navegador.
2. Mantén las carpetas css y js en la misma ubicación.
3. La página usa Tailwind y Google Fonts desde Internet.
